# El Bro - Landing Page

Landing page de intriga para El Bro mientras se construye el sistema principal.

## Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **CSS Modules** - Styling

## Getting Started

### Instalación

```bash
npm install
```

### Desarrollo

```bash
npm run dev
```

La landing estará disponible en `http://localhost:3001`

### Build

```bash
npm run build
npm start
```

## Estructura

```
app/
├── layout.tsx       # Layout principal
├── page.tsx         # Página de landing
├── page.module.css  # Estilos de landing
└── globals.css      # Estilos globales
```

## Diseño

- **Color Primario**: Púrpura (#5a1a3d)
- **Color Secundario**: Amarillo (#ffd700)
